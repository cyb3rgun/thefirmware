# Briefing S01-B01: repository foundation, target module bench, camera bench

Track: thefirmware, Season S01. Repo `https://github.com/cyb3rgun/thefirmware` (empty; the founder grants write access). Local `C:\Projects\CYB3RGUN\THEFIRMWARE`. Implementer: CC. Architect: Mausi. Boards: two Heltec WiFi LoRa 32 V2, one PAJ7025R2 module on flying wires, four beacon clusters on IRLZ44N, 5 V 2 A supply.

## 1. Decisions

- **ESP-IDF, newest stable release installed on this machine**; CC reads `idf.py --version` and records it in D-001. If ESP-IDF is missing, STOP; installing it is the founder's hand move. No Arduino core. D-001.
- **One project, several targets** via `sdkconfig.defaults.<target>` and a `main/` per target under `targets/`, shared code under `components/` (`cgproto` radio packets, `cgusb` COBS and CRC per `usb-protocol.md`, `cgbeacon`, `cgcam`). D-002.
- **Language rules as in theserver**: English code and docs, no em dashes, `tools/check_dashes.py`, Conventional Commits by component, docs trio, briefings and handovers. D-003.
- **Flash method stated after every change**: `idf.py -p COM6 build flash monitor`, or `idf.py -p COM6 erase-flash` when NVS or partition layout changes, with a warning before erase. D-004.

## 2. Tasks

1. `chore(repo)`: init, remote, `.gitignore` for ESP-IDF, project skeleton, `docs/concept.md` and `docs/usb-protocol.md` (placed by the founder; STOP if missing), decisions, seasons.
2. `feat(cgusb)`: COBS framing, CRC-16/CCITT, message structs of `usb-protocol.md` sections 2 and 3, host side reference encoder in Python under `tools/` for tests, unit tests with the IDF test framework on the host build.
3. `feat(module)`: target `module` on Heltec 1: serial at 921600, `hello` and `hello_ack`, `beacons` driving GPIO 12, 13, 14, 25 (steady and multiplex), `status` every 30 s, ESP-NOW receive of `shot`, unicast `ack` to the pistol, forward as `shot` frame, resend until the core's `ack`, counters. OLED shows channel, mode, shots heard, shots acked.
4. `feat(pistolstub)`: target `pistolstub` on Heltec 2: sends a `shot` broadcast on the PRG button and on a timer (`--rate` via menuconfig), waits for `ack`, resends up to three times, counts, OLED shows sent, acked, resends.
5. `feat(cgcam)`: target `cambench` on a Heltec with the PAJ7025R2 on VSPI at 1 MHz: init sequence per datasheet and the trzy reference, frame read of up to 16 objects, serial print of count and coordinates at 50 frames per second, OLED shows the object count. STOP and report if the module does not answer the product id register, with the wiring and the logic level checked.
6. `docs`: `docs/measurements.md` with the bench results: shot to `ack` round trip over 100 shots at 1, 3, 5 m (median, p95, loss), forwarded frames equal heard shots, and for the camera the object count with a TV remote, a candle and, once soldered, one cluster at 1, 2, 3 m. Handover, push.

## 3. Acceptance

Both Heltecs talk; 100 shots at 3 m with zero loss after resends; theclient's serial source (B04) is not required yet, a Python host script under `tools/` decodes the frames; the camera reports objects.

## 4. Report

`idf.py --version`, `git log`, the measurement table, photos of the bench, and anything odd. A gap is a question, never a substitution.
